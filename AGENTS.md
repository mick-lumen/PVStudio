# PV Studio — Project Instructions

PV Studio is a browser-based Three.js solar panel placement application. Scope is limited to a 3D OBJ/MTL viewer, a data-driven panel chooser, and manual/automatic panel placement. Do not add shading analysis, string design, energy estimates, reports, project management, export, authentication, billing, or multi-user features.

Use strict TypeScript with zero `any` types. Every component and algorithm requires tests. Production code must contain no `console.log`. All configuration belongs in environment variables. Run `npm test`, `npm run typecheck`, `npm run lint`, and `npm run build` before completion.
